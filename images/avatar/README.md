# Avatares dos membros

Adicione aqui 10 imagens PNG com estes nomes:

`avatar-01.png`, `avatar-02.png`, ..., `avatar-10.png`.

Cada membro recebe automaticamente um avatar diferente, de forma determinística, para até 10 membros. Ao atualizar a página, ele continuará com o mesmo avatar. Se uma imagem ainda não existir, o sistema mostra as iniciais do membro como alternativa.
